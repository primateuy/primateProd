Odoo 17 Subscription Draft Invoice

Before V16, In subscription we are able to generate draft invoice when the subscription invoice is automatically generated by the scheduled action. From v16, we lost the flexibility, as odoo removed this option. This app will bring back the Configuration in Subscription Plan, where user can configure whether the invoice is posted or to be in draft state.

Features

  • Control the Invoice Status.
  • Inside Subscription Plan, tick Draft Invoicing.
  • Works as in Odoo 15 and below.

Subscription -> Configuration -> Recurring Plans

Creating new subscription

Once the CRON is executed generated invoice is in Draft.

Control the Invoice State from Recurrence Period
